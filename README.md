# Pawsitive Pet Academy - Mobile Application
A cross-platform React Native mobile application built with Expo Router for Pawsitive Pet Academy. The app allows users to browse pet care courses, calculate package discounts, and submit quote enquiries.

# Features

**Hamburger Menu / Navigation Menu:** Navigation overlay accessible across screens for routing to Home, About Us, and Course pages.

**Company Profile:** Displays the company's story and the reason to choose the company. 

**Course Catalog:** Detailed overview cards for different courses.

**Interactive Fee Calculator:** Live pricing calculator with automated tiered discount logic.

**Quote Submission:** The form automatically fills in your selected courses and total costs from the previous page.

**Order Confirmation:** Dedicated completion view acknowledging quote submission. 

# Tech StackFramework: 
* React Native with Expo

* Language: TypeScript / JavaScript

* Navigation: Expo Router   

* Version Control: Git & GitHub Desktop

# How to run the app

Make sure you have Node.js installed on your machine.

**Installation & Setup**

**Clone the repository:**

Bash
git clone https://github.com/YOUR_ORGANIZATION_OR_USERNAME/PawsitivePetAcademy.git
cd PawsitivePetAcademy

**Install dependencies:**

Bash

_npm install_

**Start the Expo development server:**

Bash

_npx expo start_

**Run the app:**

* Scan the QR code using Expo Go on your physical Android or iOS device.

* Press a for Android Emulator or i for iOS Simulator.
